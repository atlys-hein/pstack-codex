# Session pickup

Read the [Codex execution contract](../../pstack/CODEX.md). Reconstruct the resume point from task-scoped evidence and continue only the remaining authorized work.

1. Read the prior handoff, decision trail, supplied branch or PR, and relevant chat summaries through supported Codex tools. Do not guess transcript filesystem paths or scan unrelated private chats. For a long history, delegate a read-only summary when useful and pass only the relevant task scope.
2. Reconstruct intent, constraints, authorization, decisions, completed work, pending units, and the last verified artifact. Inspect the actual checkout, branch, diff, logs, PR head, and outstanding agents or processes. A previous report is useful context but does not outrank current repository or forge evidence.
3. Compare the recorded state with current state. Reuse completed checks when their code, inputs, and environment still match. Do not rerun everything reflexively. Recheck only claims whose evidence is absent, stale, or contradicted by current state.
4. Name the exact resume point and choose the appropriate playbook. Continue an existing owner when its state remains useful and the host supports it. If a worker died, preserve its changes and transfer a consolidated brief before assigning its files to a replacement.
5. Finish the requested outcome or return the requested diagnosis. Verification must cover the final artifact, including any drift since the earlier session. Do not treat old merge authority as broader than the original grant.

Reply with where the prior work stopped, what was reused, what needed rechecking and why, the resume point, and the resulting outcome.
